# 📬 JoDev Mail Studio — Atelier de Recueil d'Avis sur les Templates d'Emails

Ce dépôt autonome héberge l'atelier interactif de prévisualisation et de recueil d'avis pour les nouveaux templates d'emails de **JoDev (Jovis YAYI)**.

## 🚀 Fonctionnalités
- **Comparateur interactif en direct** : Visualisez et comparez les différentes propositions de design (Épure Executive sans bordure, Doux Naturel, Sombre Fluide, et Ancien Design).
- **Double perspective (Bureau & Mobile)** : Simulez le rendu réel sur écran d'ordinateur (600px) et sur smartphone (390px).
- **Deux flux d'emails couverts** :
  1. *Prospection B2B* (campagnes d'audit digital et propositions stratégiques)
  2. *Accusé de réception* (notifications instantanées suite au formulaire de contact du site)
- **Widget de vote & avis en 1 clic** : Vos testeurs peuvent formuler une remarque et vous l'expédier directement sur WhatsApp ou par email d'un simple clic.
- **Emplacement réservé pour le logo officiel** : Tous les templates intègrent un slot propre pour accueillir votre logo officiel dès qu'il sera fourni.

## 💻 Utilisation Locale
Pour lancer le visualiseur en local :
```bash
# Lancement direct avec npx
npx serve .

# Ou ouverture directe du fichier dans votre navigateur
open index.html # Mac
start index.html # Windows
```

## 🌐 Déploiement en 1 Clic (Pour partager le lien à vos contacts)
### Option A : Déploiement Vercel
```bash
npx vercel
```
*(Le projet est prêt sans configuration requise)*

### Option B : GitHub Pages
1. Poussez ce dépôt sur votre compte GitHub.
2. Rendez-vous dans **Settings > Pages > Branch : main > / (root)**.
3. Partagez l'URL générée à votre entourage pour récolter leurs avis en direct !
